
Энэхүү лабораторийн ажлаар веб хөгжүүлэлтийн үндсэн орчин болох Node.js, npm, PHP, Git болон Visual Studio Code-ийг тохируулж ашиглалаа. HTML, CSS, JavaScript ашиглан статик веб сайт үүсгэж, PHP локал серверээр ажиллуулан browser дээр шалгасан.

Мөн GitHub repository үүсгэж, төслөө local компьютерт clone хийж, `git add`, `git commit`, `git push` командуудын дарааллыг хэрэгжүүлсэн. Цаашлаад feature branch үүсгэж, `main` branch-тэй merge хийсэн. Хоёр branch нэг файлын ижил хэсгийг өөр өөрөөр өөрчилснөөс merge conflict үүсэж болохыг туршиж, conflict marker-уудыг танин, VS Code ашиглан шийдвэрлэж сурсан.

Энэхүү ажлын үр дүнд Git болон GitHub ашиглан веб төслийг хадгалах, өөрчлөлтийг хянах, branch-ээр хөгжүүлэх, merge хийх болон гарсан conflict-ийг зөв шийдвэрлэх үндсэн мэдлэг, практик чадвар эзэмшлээ.

- `index.html` - Home page
- `about.html` - About page
- `style.css` - Website styles
- `script.js` - JavaScript interaction
